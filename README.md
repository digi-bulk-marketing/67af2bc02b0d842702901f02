# Email Sender

Email Sender by BITBEAST PRIVATE LIMITED.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/67af2bc02b0d842702901f02/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Email Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/67af2bc02b0d842702901f02/releases/latest) and reinstall.
